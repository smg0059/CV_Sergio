# CV Sergio

Página web personal / currículum online.

## Contenido

- `index.html` — estructura de la página
- `styles.css` — estilos
- `script.js` — lógica e interactividad
- `img/` — imágenes (foto de perfil)

## Ver en local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```

## Despliegue

Puede publicarse gratis con **GitHub Pages**: Settings → Pages → Source: `main` / `(root)`.
